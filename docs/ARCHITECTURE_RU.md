# Архитектура и структура

Новое ядро развивается вокруг общей AST, точных GUI-ссылок и сохранения исходной структуры. Оно восстанавливает GUI из Galaxy и дополняет готовое дерево только изменёнными участками.

```text
src/
  trigger_ast_core/
    analysis/       Анализ кода и зависимостей
    model/          AST, символы, владельцы исходных файлов
    types/          Типы, значения и совместимость
    bindings/       Привязки Galaxy → GUI, шаблоны и области видимости
    gui/            Контракты GUI-узлов
    conversion/     Стадии преобразования
    incremental/    Дозаполнение существующей разметки
    lowering/       Общие проверяемые преобразования
    verification/   Проверки эквивалентности и защитные условия
    diagnostics/    Диагностика причин REVIEW
  map_global_repair_v*/  Реально используемые снимки модулей конвертера
  map_proof_v*/          Реально используемые модули полной проверки
benchmark/oracle/        Независимый oracle с исходным manifest из 304 файлов
maps/                    Все 339 позиций и отдельные списки 103 / 222 / REVIEW
validation/              Хеши, недостающие ссылки, доступность доказательств
docs/                    Архитектура, критерии приёмки, reverse engineering
history/                 Сохранившиеся фрагменты журнала изменений
licenses/                Лицензии и notices включённых upstream-компонентов
tools/                   Проверка целостности публичного снимка
```

Точки входа:

- `src/map_global_repair_v569_template_formal_domain_2026-10-30/worker.mjs` — конвертер.
- `src/map_proof_v570_closed_literal_loop_snapshots_2026-10-30/cli.mjs` — полная проверка.

Версионные каталоги содержат исполняемые зависимости, а не только историю тестов. Их сохранение в текущем source snapshot нужно для анализа и последующей консолидации.

При разрешении GUI используются Library + Type + Id, область видимости, владелец параметра и ожидаемый Preset. Одно имя или равное значение `null` не доказывает совместимость ссылок.
Режим `preserve-source` сохраняет исходный Custom Script и отдельные Galaxy-файлы. Их полный перевод в GUI относится к отдельному `full-gui`.
Атрибуты и ссылки Galaxy должны восстанавливаться согласованно и с подтверждённым происхождением.
