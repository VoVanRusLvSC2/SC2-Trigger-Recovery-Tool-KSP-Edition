Добавлены общие proof-view модули, не меняющие исходный Galaxy/экспорт:
- bound-boolean-literal-comparison.mjs: только единственная реально bound локальная/глобальная bool-переменная или параметр; сравнение с true/false заменяется эквивалентным чтением/отрицанием с одним вычислением. Int truthiness, неизвестные ссылки, вызовы и обращения к полям не угадываются.
- closed-integer-literal-arithmetic.mjs: только закрытые десятичные int-литералы, +, -, *, BigInt-расчёт и каждый промежуточный результат в signed int32. Нет float/fixed, переполнения, деления, чтения const/state или вызовов.
- local-initializer-sequence.value-handles.mjs: расширен доказанный перенос скалярной инициализации на встроенные value/handle carriers. Номинальные/ref-типы, массивы, static, forward reads и state-reading const по-прежнему являются барьерами.
- inert-global-initializer-order.mjs: переставляются только закрытые literal stores встроенных global-carriers через неисполняемые определения. Include, структуры/массивы, зависимые и вызывающие код инициализаторы — барьеры. Все объявления/значения сохранены; обратная перестановка должна восстановить полную исходную AST. Перестановка literal stores есть, перестановки наблюдаемых эффектов нет.
- finite-program-equivalence.mjs: один общий API нового слоя бенчмарка. Он повторно запускает прежние и новые конечные правила на обоих полных исходных текстах, существующее доказательство Native-prefix и позиционные имена формальных параметров прототипов, затем требует полного exact неизменённого oracle.
