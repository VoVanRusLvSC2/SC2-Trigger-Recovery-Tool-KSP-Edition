
2026-10-23 — R840–R854: обычный прогон Star Party восстановлен общим исправлением фаз локальной инициализации.
- R840 на V330 и контроль R842 на V328 получили одинаковые 309 raw GUI-узлов: 308 ссылок на generated trigger initializers и блок их прототипов. Архив, preparation SHA и исходный серверный Galaxy совпадают с ранее прошедшим V315. Следовательно, это не новая регрессия от исправления лексических областей V330.
- Сравнение стадий показало: корневой код до structural-for pass имеет тот же SHA, что в V315; затем шесть compiler local-initialization циклов переставали защищаться от общего lowering. R844 сравнил распознавание исходных функций V315/текущей версии: восемь префиксов потеряны, включая два настоящих trigger callback. Потеря этих двух callback давала каскад отказа InitTriggers и 308 лишних интерфейсных вызовов.
- V331 исправляет общую модель порядка, а не имена функций/карт. Константные declaration initializers выполняются в фазе объявлений; mutable Variable Initialization идёт после неё. Предыдущая модель неверно сравнивала обе фазы как один порядок GUI Variables. Новая модель требует точную исходную AST-expression у константного объявления. Проверки зависимости чтения от уже/ещё не инициализированного значения и запрет перестановки потенциально наблюдаемых выражений сохранены.
- R845: два теста фаз проходят. R847 на реальной исходной карте восстановил семь из восьми префиксов, включая ОБА trigger callback. Один оставшийся нестандартный auto-thread prefix не получил ослабления консервативной проверки. R850: пять дополнительных проверок проходят, включая исходный пример, где старая версия меняла порядок зависимых unit-инициализаций; текущая либо сохраняет исходный порядок, либо честно отказывает. Структурный scalar field остаётся конкретного типа, новые Native не создаются.
- R848, полный обычный прогон 0509 Star Party на V331: генерация и упаковка прошли за 344.235 с, независимый packed source/GUI verifier R796 за 35.266 с, исходный raw oracle за 3.219 с. 126 посторонних payload сохранены, исходный Galaxy сохранён, получен один вариант карты. GUI: 0 raw-узлов, 0 Custom Script, 0 новых runtime-тел. Есть одно РАНЕЕ РАЗРЕШЁННОЕ Native-описание существующего TriggerAddEventUnitRegion для Action с явным trigger: штатный Event имеет неявный target и не подменён. ABI trigger/unitref/region/bool проверена. Эту единицу не называем нулём и новой runtime-обёрткой.
- Неизменённый бенчмарк R848: REVIEW, 19 различающихся функций, 0 пропущенных функций, атрибуты полны. Результат соответствует прежнему уровню V315. REVIEW не приравнен к PASS; новый Editor export и доказательства оставшихся различий ещё нужны. GUI-проверка не названа штатной компиляцией.
- R852: после подтверждения завершения собственных hidden workers объединены ещё 45 побайтно одинаковых private payload-копий. Освобождено 79 880 192 байта; все пути/байты сохранены, новые shared streams read-only. Чужие процессы и оригинальные карты не тронуты. Для native job резерв не уменьшался.
Новое исправление использует одну общую фазовую модель во всех достижимых вариантах prefix codec; Source/GUI gate и oracle не ослаблены. CURRENT/V193 не продвигался. Нового whole-map PASS пока нет.
