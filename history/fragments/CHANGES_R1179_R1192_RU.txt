- В оригинальном Project Haven Classic 0549 обнаружен gt_Bleed_Func с блоком
  if(testConds) перед if(!runActions). Блок содержит цепочку проверок, каждая
  отвергает выполнение через return false. Старый конвертер не распознавал
  положительные failure predicates/else-if chains и оставлял весь блок в Actions.
  SDK затем ставил action guard перед ним. При testConds=true/runActions=false
  получалось true без исходной проверки условий. Это реальная ошибка, а не

  вызовы сохраняют количество/порядок вычислений и короткое замыкание. Никаких
  названий карт или частных API в алгоритме нет; обёртки/runtime-тела не создаются.

  вместо переноса после action guard. Также запрещены исходные conditions после
