2026-10-23. Квалифицированная граница исходный код -> GUI, V344/V345.

R934/R935: построена общая модель объявлений, которые фактически создаёт GUI.
Различаются обычная Variable, неявный trigger handle от Trigger и обычная
FunctionDef. У AoS прежние «131 global» состоят из 39 обычных переменных и
92 handles триггеров; ещё есть 7 обычных функций. Source.kind=VariableDeclaration
сам по себе не означает, что в GUI нужен элемент Variable: gt_* принадлежит
конкретному Trigger по Library/Type/Id. Не используются имена карт/allowlist API.

Модель проверяет настоящую исходную AST-декларацию и её SHA/область видимости,
квалифицированное GUI-объявление, точное ожидаемое имя генератора, носитель типа,
constant/reference-признаки, число/порядок параметров и полные оси массивов.
Имя используется только для выбора кандидатов; неоднозначность/чужой owner
оставляют явный отказ. Нативно игнорируемый Variable.NoScriptPrefix не считается
работающей возможностью GUI. Все данные остаются facts, не разрешением raw fallback.

Массивы разбираются общей AST-функцией unwrapArrayType с восстановлением порядка
осей исходника. Прямой обход вложенных ArrayType имеет обратный порядок;
первый положительный тест int[2][3] выявил это до подключения модели к runtime.
Использован общий существующий AST-helper, тест оставлен на неравных осях 2/3.
Размер Galaxy сравнивается с включительной границей GUI +1 точной целочисленной
арифметикой. Неполные оси не превращаются в scalar и не угадываются из исходника.

Квалифицированные GUI-идентичности и имена индексируются один раз. Отдельный
поиск всего каталога на каждый ParamDef устранён до фиксации версии. Каталог
имеет неподлежащее сериализации удостоверение; поддельный JSON/объект с resolve
не принимается анализатором. Перед использованием проверяется неизменность
GUI-снимка, включая владельцев, корни, типы, параметры и оси. Постоянного кеша нет.

V344/R938/R939: общий анализатор исходных компонентов умеет принимать такой
свежий каталог фактического GUI. Только подтверждённые исходные ссылки получают
outboundGuiBindings. Несовместимость ABI остаётся прежней явной обязанностью;
обращения GUI к исходному storage не отменены. Без переданного каталога обычная
конвертация сохраняет прежние ограничения. Эта стадия не разрешает автоматически
материализовать незакрытый исходный компонент или обойти финальную GUI-проверку.

R936: публичный sc2_convert_xml реально скомпилировал отдельный пример через
собственный скрытый Editor. Проверены GUI int, int[2][3], неявный gt_Alarm и
обычная gf_Do(int), используемые тремя исходными функциями. В завершающем коде
драйвера обнаружена ошибка отчётности: локальная строка progress затенила прежний
template-report, и readFile получил undefined после завершённого native job.
Неудачный хвост DRIVER_FAILED сохранён; повторный Editor не запускался.
R937 независимо проверил сам завершённый публичный native job, SHA/размер экспорта,
неизменность шаблона и source XML, точные AST трёх исходных тел, уникальность
объявлений и их порядок. Штатная компиляция подтверждена. Все GUI globals стоят
до использующих их source-функций; gf_Do имеет точную void(int) ABI. Это capability
на тестовом примере, не PASS AoS. В примере один специально авторский блок
CustomScript; новых Native или runtime-обёрток нет.

R935 на старом полном снимке смог проверить 127 из 138 объявлений; 11 массивов
были отклонены по ARRAY_DIMENSIONS_NOT_COMPLETE. Причина — диагностический DTO
не сохранял arraySizes. R940/V344 сохраняет именно реальные arraySizes, не
восстанавливает их предположением из Galaxy. Проверены detached-копия осей,
полнота tree items и прежний общий UTF-8 cap 8 MiB с явным неполным результатом.

R942: на свежем настоящем GUI-снимке AoS проверены все 138 объявлений:
